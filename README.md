# SalesFlow CRM 🚀

A robust Full-Stack Customer Relationship Management (CRM) system designed to streamline customer interactions, track sales pipelines, and optimize business workflows.

🔗 **[Live Demo](https://salesflow-crm-ten.vercel.app)**

---

##  Features
- *Customer Management:** Easily create, update, view, and manage customer profiles and interaction history.
- **Sales & Pipeline Tracking:** Monitor sales progress, deals, and daily business performance.
- **Interactive Dashboard:** Modern interface providing quick insights into customer data and metrics.
- **Full-Stack Architecture:** Properly decoupled Frontend and Backend structure for maximum scalability.

##  Tech Stack
- **Frontend:** React (Vite), Modern CSS / UI Components
- **Backend:** Node.js, Express.js
- **Database:** ( MongoDB)
- **Deployment:** Vercel

## Project Structure
The repository is split into two main sections:
- `/frontend-vite`: The interactive user interface built with Vite for optimal performance.
- `/backend`: The RESTful API handling server logic, routing, and database connections.

##  Getting Started

### Prerequisites
- Node.js installed on your local machine.
